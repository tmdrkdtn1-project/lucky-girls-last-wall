# 0. 이 문서의 역할

이 문서는 “카린 원화를 예쁘게 다시 그리는 문서”가 아니라,  
**카린의 공식 MASTER를 도트 생산 가능한 상태로 정리하는 전처리 가이드**다.

즉 목표는:

```text

→ 96×96 SD BASE
→ Pixelorama 제작
```

# 5. 꼭 추출해야 할 카린 핵심 요소

## 5.1 반드시 남길 것
- 긴 흑발
- 붉은 헤어 장식
- 검정 + 진홍 컬러 구조
- 날렵한 상체
- 잘록한 허리
- 골반/허벅지 강조 실루엣
- 단검
- 암살자 느낌의 타이트한 의상
- 짧은 천/망토성 움직임 요소

## 5.2 줄여도 되는 것
- 작은 버클
- 미세 장신구
- 얇은 금속 부품
- 미세한 자수 / 패턴
- 세밀한 옷 재질 표현
- 복잡한 끈 장식 여러 겹

## 5.3 절대 잃으면 안 되는 것
- “검정+진홍 암살자”라는 첫인상
- 긴 머리 + 붉은 장식
- 허리-골반 실루엣
- 카린의 위험하고 도발적인 분위기
- 단검 사용자라는 인상

# 6. SD 단순화 기준

## 6.1 머리
### 유지
- 긴 전체 실루엣
- 앞머리 큰 덩어리
- 뒤머리 덩어리 2~3개
- 붉은 장식 위치

### 축약
- 잔머리
- 세밀한 꽃잎 수
- 너무 얇은 장식 라인

## 6.2 얼굴
### 유지
- 얼굴형 전체 방향
- 눈의 위치
- 냉정한 표정 기조

### 축약
- 속눈썹 세부 묘사
- 입술 세부선
- 코의 세밀한 구조

## 6.3 상체
### 유지
- 밀착형 의상
- 가슴 실루엣
- 상체에서 허리로 좁아지는 라인

### 축약
- 가슴 위의 미세 절개선
- 세밀한 장식 문양

## 6.4 허리/골반/하체
### 유지
- 허리 잘록함
- 골반 라인
- 허벅지 강조
- 가터/스트랩

### 축약
- 아주 작은 스트랩 세부
- 작은 장식 쇳조각

## 6.5 무기
### 유지
- 단검 형태
- 칼날 / 손잡이 구분

### 축약
- 손잡이의 미세 장식
- 과도한 문양

- 허벅지 스트랩이 캐릭터 매력을 살리는가
- 노출보다 곡선/핏/절개가 더 중요한가

## 목표
작은 화면에서
- “섹시한 캐릭터다”
- “암살자다”
- “카린이다”
가 동시에 읽혀야 한다.

# 8. 팔레트 정리 절차

## 8.1 먼저 뽑을 색 그룹
1. 피부
2. 머리
3. 붉은 장식/붉은 의상 포인트
4. 검정 의상
5. 금속/무기
6. 눈/작은 포인트

## 8.2 출력 형식
가로 팔레트 스트립 PNG 추천.

예:
```text
SKIN_LIGHT / SKIN_BASE / SKIN_SHADOW
HAIR_LIGHT / HAIR_BASE / HAIR_SHADOW
CRIMSON_LIGHT / CRIMSON_BASE / CRIMSON_DARK
OUTFIT_LIGHT / OUTFIT_BASE / OUTFIT_SHADOW
METAL_LIGHT / METAL_DARK
EYE_ACCENT / OUTLINE
```

## 8.3 주의
- 검정과 머리 검정, 의상 검정을 같게 쓰지 말 것
- 피부색은 의상에 묻히지 않게 충분히 밝게 둘 것
- 붉은색은 장식과 스킬 이펙트에 재사용 가능하게 둘 것

# 9. SD GUIDE 이미지 제작 순서

## STEP 1 — 전체 실루엣 스케치
- 96×96 기준으로 대략적인 비례를 잡는다
- 머리, 상체, 허리, 골반, 다리, 무기 전체만 본다

## STEP 2 — 실루엣 비교
다음 두 가지를 비교한다.
- 원화 인상
- SD로 줄였을 때 읽히는가

## STEP 3 — 큰 색 블록 배치
- 머리: 검정
- 장식: 빨강
- 의상: 검정/진홍
- 피부: 밝은 톤
- 무기: 금속색

## STEP 4 — 캐릭터 인식 테스트
이미지를 멀리서 축소해서 보고 다음을 체크한다.
- 카린인지
- 암살자인지
- 머리와 의상이 분리되는지
- 허리/골반이 보이는지

## STEP 5 — 최종 SD GUIDE 저장
PNG로 저장:
```text
08_KARIN_SD_GUIDE.png
```
