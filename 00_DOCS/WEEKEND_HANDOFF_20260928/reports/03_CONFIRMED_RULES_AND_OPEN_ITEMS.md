# 확정 규칙 및 미결정 항목

## 근거 우선순위

최신 사용자 직접 확정 → 현재 코드/데이터와 대조한 문서 → 원본 도감 → 과거 기록 순으로 충돌을 해석한다.
코드 동작이 사용자 의도와 다르면 구현 결함으로 남기며 새 규칙으로 승격하지 않는다. V4_2의 후보값도 자동으로 출시 확정값으로 승격하지 않는다.

## 확정된 프로토타입 규칙

- BASIC은 초기 플레이 프로파일. 현재 코드 ARIA 보유, Lv10, Stage1, 500G.
- MASTER는 20영웅 전원 보유 의도. Stage 선택→기본/무한골드→Lv10/20/30/50/100→시작. 현재 Stage1만 활성화.
- Lv10=S1, Lv20=S1+S2, Lv30/50/100=S1+S2+S3. TD와 RPG 수동/AUTO에 같은 잠금 의도.
- 전설8: 아리아·유나·리엘·루비·에리카·세라·레이나·카린.
- 신화12: 벨·미아·아이린·네온·샤샤·루나·비올라·클로에·아델·니아·오로라·이브.
- 무료소환 후보는 보유 영웅∩요구 희귀도∩이번 전투 미소환. 동일 영웅 중복 금지. 최대5슬롯, 전설2명 보상은 서로 다르게, 남은 슬롯만큼만 생성.
- 후보 없음/슬롯 가득 참은 대체보상 없이 “펑!” 실패. 일반 조합도 동일 영웅 중복 금지.
- 주의: 현재 구현의 미소환 판정은 현재 units 기준이다. 향후 영웅 소비/퇴장 후 재소환까지 금지할지는 별도 계약으로 명시해야 한다.

## Lucky Roulette 현재 계약

- 초기 JACKPOT 0%, W1~W9 종료 +5%p, 자연 누적 최대45%. 회전 후0%. 중간보스 선택 보상 +20%p, 전체 최대100%.
- 표시 JACKPOT%가 절대 당첨 확률. 실패 잔여 확률 안에서 LUCKY:BONUS:MISS=1.5:1.8:1.0. MISS 페널티 없음.
- JACKPOT: 신화1 / ATK·공속+30% / 전설2 / 2000G 중 선택.
- LUCKY: 전설1 / ATK·공속+20% / 1000G 중 선택. BONUS: +10% / 500G 중 선택.
- 스테이지 버프 누적 최대40%, 현재·추후 유닛 적용 의도. 회전·보상 선택 동안 정지.
- W5 중간보스 처치: 1000G / 전설1 / JACKPOT+20%p 중1, 선택 후 재개.
- 계약 존재와 현재 정상 플레이 여부는 별개이며 F04/F05 수정이 필요하다.

## 전투 기준

- 18×10 그리드, 10웨이브×40초. W1~9 조기 전멸 시 남은 정수초×5G. 생존 적은 다음 웨이브 이월.
- W5 중간보스. W10 3초 경고/6초 보스/40초 광폭. TD 보스 사망 후 RPG 보스 돌격.
- TD에서 소환한 영웅만 RPG 참가, 자동 빈칸 보충 없음. RPG 보스 최종 사망 시 Stage Clear, 전멸 시 패배.
- 일반유닛/영웅 이동·교대 후5초 잠금. 조합 시 일시정지, 재료 위치 중 배치 선택. 아리아=기사단장+기사단장.

## 충돌·미결정·미완성

| 분류 | 항목 | 처리 |

| 확정된 테스트 예외 | V4_2 S3=Lv60/3차 한계돌파 vs MASTER Lv30 | 원본 보존, 프로토타입은 사용자 최신 Lv30 우선 |
