## 이번 정리에서 재현한 문제

수정 없이 원본 함수를 분리 실행했다. 최소 UI 대체 객체를 쓴 함수 검사이며 브라우저/Android 실기기 종단 검사는 아니다. 코드 위치는 동봉한 `repository/app/src/main/assets/js/game.js` 기준이다.

1. **F01 아델 누락:** 42~43행 `ADELE`/`ADEL` 불일치. MASTER 보유20이나 실제 후보는 전설8+신화11이다.
2. **F02 전체 소환 미연결:** 37~39행 레시피는 ARIA만, 108~113행 생성이 레시피에 의존. YUNA/BELL 생성 false, ARIA true 재현. 신화 보상은 후보가 있어도 생성할 수 없다.
3. **F03 무한골드 미작동:** 46행 helper가 있지만 239~250행 구매/강화는 직접 차감. 무한 플래그 true에서 80G 구매 후 500→420 재현.
4. **F04 룰렛 회전 차단:** `openLuckyModal`은 `luckyOverlayOpen=true`로 설정하고 `luckySpin`은 같은 상태면 null 반환. 창 열기→회전 호출에서 null 재현. 실제 버튼은 이 경로를 사용한다.
5. **F05 중간보스 확률 손실:** 40%에서 +20%p로 60%를 만든 뒤 W9 종료를 적용하면 45%로 감소. 자연 증가 45% 상한과 누적 보너스 100% 상한의 구현 분리 필요.

추가 코드 확인: `startRpgBattle`은 전원을 ARIA 스탯/ID로 구성한다. `heroLevel`은 해금 판정에 쓰이지만 능력치 성장식에는 연결되지 않았다. 이 두 항목을 전영웅 구현 완료로 오인하면 안 된다.
