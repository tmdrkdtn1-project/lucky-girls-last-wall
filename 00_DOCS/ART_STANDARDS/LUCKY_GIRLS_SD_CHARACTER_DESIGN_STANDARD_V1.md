# LUCKY GIRLS — SD CHARACTER DESIGN STANDARD V1

**문서 목적**  
《Lucky Girls: Last Wall》의 모든 플레이어블 캐릭터에 공통 적용하는 SD 도트 캐릭터 설계·제작 기준.  
본 문서는 캐릭터별 개별 디자인 문서보다 상위의 공통 규칙으로 사용한다.

---

## 0. 적용 전제

- 본 기준의 섹스어필 관련 규칙은 **성인 캐릭터에만 적용**한다.
- 캐릭터의 공식 MASTER 일러스트/턴어라운드가 존재하면 그것을 최우선 기준으로 삼는다.
- 인게임 핵심 자산은 **SD 도트 스프라이트**이며, 고해상도 일러스트는 도감·대표 이미지·필요한 이벤트 CG 등 제한된 용도로 사용한다.
- 신규 고해상도 일러스트를 반복 생성하기보다, 확정된 MASTER를 게임 자산으로 변환하는 것을 우선한다.

# 1. 프로젝트 비주얼 전략

## 1.1 핵심 방향
- 빠른 생산
- 높은 캐릭터 식별성
- 모바일 화면 가독성
- 반복 제작 가능한 템플릿 구조
- 캐릭터별 매력 포인트 유지
- 1인 개발에서 감당 가능한 애니메이션 규모

## 1.2 우선순위
1. 실루엣
2. 헤어 스타일
3. 대표 색상
4. 얼굴 포인트
5. 대표 장식
6. 무기
7. 캐릭터별 섹스어필 포인트
8. 세부 장식

세부 장식이 실루엣이나 가독성을 방해하면 과감하게 축약한다.

# 2. SD 기본 규격

## 2.1 기본 캔버스
- 기본 캔버스: **96 × 96 px**
- 실제 캐릭터 점유 높이: **약 70~76 px**
- 배경: 투명
- 기본 체형: **약 2.8~3등신**
- 기본 시점: **3/4 정면**
- 필요 시 좌우 Flip 재사용 가능

## 2.2 기본 팔레트
권장 목표: **12~16색**

기본 역할:
- 피부 밝음 / 기본 / 그림자
- 머리 밝음 / 기본 / 그림자
- 주색 밝음 / 기본 / 그림자
- 보조색
- 금속 밝음 / 어두움
- 눈·마법·캐릭터 포인트
- 외곽선

순수 검정만으로 명암을 처리하지 말고, 캐릭터 색조에 맞춘 짙은 유채색 또는 회색을 활용한다.

---

# 3. 캐릭터 식별 규칙

각 캐릭터는 반드시 아래 항목을 정의한다.

### A. Silhouette Key
작은 화면에서도 알아볼 수 있는 전체 윤곽.

### B. Hair Key
헤어 길이, 묶임, 장식, 앞머리 등.

### C. Color Key
주색 1개 + 보조색 1~2개.

### D. Costume Key
도트에서도 남길 의상 구조 2~4개.

### E. Weapon / Prop Key
무기 또는 대표 소품.

### F. Sexy Appeal Key
성인 캐릭터의 매력을 결정하는 신체·의상 포인트 1~3개.

# 4. Sexy Appeal Design Policy

## 4.1 공통 원칙

**직접적인 핵심 부위 노출보다, 실루엣·의상 구조·절개·밀착·노출 면적을 이용한 강한 매력 표현을 우선한다.**

Lucky Girls는 성인 캐릭터의 섹스어필을 적극적으로 활용하되, 실제 배포 시에는 각 플랫폼 및 지역의 심의 기준을 별도로 확인한다.

## 4.2 적극 활용 가능한 요소

### 상체
- 타이트한 상의
- 바디수트
- 코르셋 구조
- 가슴 볼륨 강조
- 옆가슴 / 아랫가슴 계열의 의상 설계
- 깊은 네크라인
- 절개 디자인
- 시스루 또는 반투명 소재 표현
- 옷 위로 드러나는 자연스러운 가슴 실루엣

### 허리 / 골반
- 잘록한 허리
- 골반 곡선 강조
- 하이웨이스트 / 로우웨이스트 대비
- 컷아웃
- 스트랩
- 벨트
- 비대칭 의상

### 하체 / 엉덩이
- 짧은 하의
- 하이컷 / 하이레그 구조
- 엉덩이 라인 강조
- 엉덩이 골 표현
- 언더붓(엉덩이 밑살) 표현
- 높은 슬릿
- 가터 / 허벅지 스트랩
- 스타킹 / 니삭스와 맨살 대비
- 속옷 또는 란제리에서 착안한 외형 디자인

### 전체 분위기
- “가릴 것은 가렸지만 아슬아슬하게 보이는” 구조
- 바디라인을 적극적으로 드러내는 밀착 소재
- 비대칭 노출
- 움직임에 따라 매력이 살아나는 천 / 리본 / 짧은 망토

## 4.3 직접 노출 관련 기준

프로젝트 기본 제작 기준에서는 다음은 직접 노출시키지 않는다.
- 유두 자체
- 성기
- 항문

단, 의복을 착용한 상태에서의 신체 윤곽이나 실루엣 강조는 디자인 요소로 활용할 수 있다.

## 4.4 SD 도트에서의 해석

SD 도트에서는 세밀한 묘사보다 아래를 우선한다.
- 상체-허리-골반의 곡선 대비
- 가슴 볼륨이 읽히는 실루엣
- 엉덩이 / 허벅지 실루엣
- 하이컷 / 슬릿 / 가터 등의 큰 형태
- 피부 영역과 의상 영역의 명확한 대비

섹스어필은 미세한 픽셀 디테일이 아니라 **전체 실루엣과 색 블록**으로 전달한다.

기준:

# 6. 기본 애니메이션 표준

## MVP 세트

### IDLE
- 6 Frames
- 기본 호흡
- 머리 / 장식 / 천의 미세 후행

### MOVE
- 6~8 Frames
- 발, 골반, 머리의 상하 리듬 우선

### ATTACK_01
- 6 Frames
- READY → WINDUP → ATTACK → HIT → FOLLOW → RETURN

### SKILL_01
- 8 Frames
- 캐릭터별 대표 모션
- VFX는 본체와 분리

### HIT
- 3 Frames
- NORMAL → RECOIL → RECOVER

### DOWN
- 5 Frames
- HIT → FALL → FALL → GROUND → HOLD

추가 액션은 게임 플레이 필요성이 생긴 뒤 제작한다.

# 10. 공통 제작 파이프라인

```text
OFFICIAL MASTER
    ↓
KRITA PREP
    ↓
SD BASE DESIGN
    ↓
PIXELORAMA SOURCE
    ↓
ANIMATION
    ↓
AUTO EXPORT
    ↓
QC
    ↓
WAITING_MASTER_APPROVAL
    ↓
APPROVED
    ↓
FINAL / GAME INTEGRATION
```

자동화는 `WAITING_MASTER_APPROVAL`에서 반드시 멈춘다.

자동 승인 / 자동 MASTER 승격은 하지 않는다.

# 13. QC 체크리스트

### 형태
- [ ] 96×96에서 캐릭터가 명확히 읽히는가
- [ ] 다른 캐릭터와 실루엣이 구분되는가
- [ ] 얼굴 위치와 신체 비율이 프레임마다 흔들리지 않는가

### 디자인
- [ ] MASTER의 대표 색상이 유지되는가
- [ ] 헤어/무기/대표 장식이 유지되는가
- [ ] 과도한 디테일 때문에 지저분하지 않은가

### 매력
- [ ] 캐릭터별 Sexy Appeal Key가 작은 화면에서도 읽히는가
- [ ] 의상과 신체 실루엣이 캐릭터 성격에 맞는가
- [ ] 매력 요소가 전투 가독성을 방해하지 않는가

### 애니메이션
- [ ] Idle이 과하게 흔들리지 않는가
- [ ] 공격 핵심 포즈가 한눈에 읽히는가
- [ ] 프레임 사이 체형이 변하지 않는가
- [ ] 머리/천/장식의 후행 모션이 자연스러운가

### 기술
- [ ] 투명 배경
- [ ] 파일명 규칙 준수
- [ ] 태그 정상
- [ ] spritesheet 정상 Export
- [ ] JSON 정상 생성
- [ ] GAME 폴더 정상 배치
- [ ] WAITING_MASTER_APPROVAL에서 자동화 중단

# 14. 문서 우선순위

본 문서가 캐릭터 개별 작업 문서보다 상위 규칙이다.

우선순위:
1. 프로젝트 공식 MASTER
2. 본 `SD CHARACTER DESIGN STANDARD`
3. 캐릭터별 SD DESIGN SPEC
4. 개별 작업 Job / Animation Spec

캐릭터별 공식 MASTER와 본 공통 문서가 충돌할 경우, 외형 정체성은 MASTER를 우선하고 게임용 단순화 방식은 본 문서를 우선한다.
