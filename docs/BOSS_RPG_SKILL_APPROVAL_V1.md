## 승인 처리 규칙
- 승인: `APPROVED_FOR_RUNTIME`로 변경 후 공용 Effect 런타임 연결.
- 수정: 마스터 수정안을 반영한 뒤 다시 승인 대기.
- 보류: `HOLD`로 두고 런타임 미연결.
- 수치: 효과 구조 승인 후 별도 밸런스 패스에서 확정.
