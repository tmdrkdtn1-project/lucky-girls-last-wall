## 완료한 확인

- 지역/대표 스테이지/진입로 수 및 W5/W10 보스 이름: 로컬 V4.2 원문 대조.
- 6개 좌표 설계: 18×10 범위, 상하좌우 연결, 성문 도달, PATH와 DEPLOY 분리, 방벽 위치, CC/GG/CC 성채 구조 확인.
- 컨셉 이미지 6장 육안 확인: 지역 테마, 높은 탑뷰, 도로 대비, 서로 다른 진입 구도 확인. UI·인물 초상은 사용하지 않음.
- 이미지 생성 방식: 내장 image_gen. 최종 프롬프트는 IMAGE_PROMPTS_V1.json.

## 이미지와 설계도의 차이

PNG는 환경 컨셉이다. 격자/배치칸 수를 정확하게 재현한 게임 배경이나 타일셋이 아니다. 모든 PNG에서 성채 2×3과 C 4칸 표현은 재정리가 필요하고, 큰 배치 패드는 실제 구현 시 1논리 타일 안의 3슬롯로 맞춰야 한다. 생성 그림의 길 굽이도 좌표와 일대일 일치하지 않는다.

- Stage 1: 단일 굽이길 방향은 부합. 배치 패드 수와 성채 방어칸은 도식으로 보정 필요.
- Stage 8: 오아시스 양안과 우상단 성채는 부합. 북·남 길이 차이는 좌표 도식을 기준으로 구현.
- Stage 13: 두 교량과 좌측 성채는 부합. 좌측 장식 부두가 추가 경로처럼 보일 수 있어 실제 게임 배경 제작에서 경계 강화 필요.
- Stage 18: 두 계단길과 하단 성채는 부합. 컨셉의 좌우 대칭을 실제 좌표의 비대칭 경로로 조정 필요.
- Stage 23: 세 진입 회랑은 부합. 하부와 중앙이 비교적 일찍 만나는 그림이므로 실제 합류 지점은 도식 기준.
- Stage 30: 사방 진입과 중앙 성채는 부합. 그림의 정면 성문 대신 서·동 접근의 종착 판정과 중앙 GG 구조를 명확히 맞춰야 함.

## 검증 전

사거리, 적 속도, DPS, 실교전 시간, 3슬롯 동시 표시, 보스 충돌, 실제 승률, 모바일 성능. 기존 시트의 1칸 점유 규칙과 사용자 최신 3슬롯 지시 간 충돌은 최신 지시를 우선했다. 성채 C 슬롯 세부 정책은 후속 확인 항목이다.
